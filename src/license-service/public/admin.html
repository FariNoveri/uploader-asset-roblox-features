Maintenance & update aplikasi

Aplikasi aktif memeriksa pengaturan tiap 30 detik. Update tersedia otomatis diunduh, diverifikasi dengan SHA-256, lalu dipasang dengan membuka ulang EXE.

Host file EXE pada URL HTTPS publik, lalu isi versi baru dan SHA-256 file yang sama. Jangan mengaktifkan update sebelum file rilis tersedia. Versi harus lebih tinggi dari versi pengguna.

Lisensi & aktivasi perangkat

Creator ID dan tipe akun yang dikunci ditampilkan di halaman Data akun.

Data yang ditampilkan berasal dari persetujuan pengguna: ID instalasi acak (bukan fingerprint hardware) dan IP koneksi yang diterima Cloudflare. Roblox API key tidak pernah dikirim ke server lisensi. Tentukan masa simpan data dan hapus data yang tidak lagi dibutuhkan.
