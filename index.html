Fari Noveri

Upload banyak lagu ke Roblox, lalu tinggal tidur

Aplikasi sedang maintenance

Alat ini gunanya apa?

Biasanya upload lagu ke Roblox harus satu per satu lewat website. Alat ini membantumu mengupload banyak lagu sekaligus. Kamu tinggal memilih lagunya, lalu biarkan jalan sendiri sampai selesai.

Sebelum mulai, ada beberapa hal yang perlu disiapkan. Semuanya dijelaskan satu per satu di halaman berikutnya, jadi tenang saja.

Cek akun dan lagumu dulu

  • Akun Roblox kamu sebaiknya sudah verifikasi identitas (istilahnya ID verified). Kalau sudah, kamu boleh upload 100 lagu tiap bulan. Kalau belum, cuma 10 lagu.
  • Lagu harus berformat mp3, ogg, wav, atau flac. Ukuran maksimal 20 MB dan panjang maksimal 7 menit.
  • Lagunya harus buatanmu sendiri atau kamu punya izin memakainya. Lagu orang lain biasanya ditolak Roblox.

Setelah diupload, tiap lagu diperiksa Roblox dulu. Jadi hasilnya belum tentu langsung bisa dipakai.

Buat kunci API

Kunci API itu seperti password khusus yang mengizinkan alat ini mengupload atas nama akunmu. Kamu membuatnya sendiri di website Roblox.

  1. Buka halaman kunci API Roblox, lalu klik Create API Key.
  2. Isi nama bebas, misalnya upload-lagu.
  3. Di bagian Access Permissions, pilih Assets API, klik tombol tambah, lalu centang Read dan Write. Kalau nanti mau memberi izin lagu ke komunitas tertentu, tambahkan juga Asset Permissions dengan Write kalau pilihannya ada. Kalau lagunya untuk grup, buat kunci ini dari halaman kredensial grupnya.
  4. Di bagian Security, kalau ada pilihan Restrict IP addresses, biarkan tidak dicentang supaya kunci ini bisa dipakai dari komputermu. Kalau kolom IP wajib diisi, isi 0.0.0.0/0.
  5. Klik Save & Generate Key, lalu salin kuncinya. Kunci ini cuma muncul sekali, jadi jangan tutup halamannya sebelum kamu menyalinnya.

Jangan kasih kunci ini ke siapa pun. Kalau sempat bocor, hapus di halaman yang sama dan buat yang baru.

Isi data akunmu

Creator ID adalah nomor akunmu di Roblox. Buka profilmu, lalu lihat angka di alamat webnya, misalnya roblox.com/users/1234567/profile. Angkanya 1234567. Kalau mau upload ke grup, ambil angka dari alamat halaman grupnya dan centang kotak grup di bawah.

Creator ID dan jenis akun akan dikunci ke lisensi ini setelah disimpan pertama kali. API key tetap disimpan lokal dan tidak dikirim ke server lisensi. Creator ID/jenis akun yang disimpan dapat dilihat administrator.

Semua siap

Di halaman berikutnya kamu tinggal memasukkan lagu, lalu klik Mulai upload. Beberapa hal yang perlu kamu tahu:

  • Jendela aplikasi Fari Uploader jangan ditutup, dan komputer harus tetap menyala. Tab browser ini boleh ditutup.
  • Selama upload berjalan, komputer tidak akan masuk mode sleep.
  • Lagu yang gagal bisa dicoba lagi dengan tombol Coba ulang yang gagal.
  • Lagu yang berhasil akan menampilkan ID. Di Roblox Studio, ID itu dipakai dalam bentuk rbxassetid://ID.
  • Program mengecek ke Roblox tiap satu menit apakah lagunya disetujui atau ditolak. Pemeriksaannya bisa makan waktu beberapa menit sampai lebih lama.

Sedang dalam pengembangan

File lagu hanya disimpan sementara di memori, bukan di disk. Data aplikasi disimpan di memeriksa lokasi.... Jika aplikasi ditutup sebelum upload berhasil, pilih ulang file tersebut untuk mencobanya lagi.

Reset data aplikasi di perangkat ini

Menghapus lisensi tersimpan, kunci API Roblox, pengaturan, riwayat antrean, playlist, dan log lokal di lokasi data aplikasi. Aplikasi akan ditutup lalu dibuka kembali; masukkan lisensi lagi setelah reset. Data akun yang sudah tersimpan di server lisensi tidak terhapus.

Impor lagu lama dari akunmu

Roblox tidak menyediakan cara mengambil daftar semua audio lewat kunci API. Jadi tempel ID atau link audio yang mau dimasukkan ke riwayat. ID-nya adalah angka panjang di alamat halaman audio itu di Creator Hub. Boleh banyak sekaligus, pisahkan dengan enter atau spasi. Tiap audio ditandai Sama atau Beda akun dibandingkan Creator ID di pengaturan, karena audio milik akun lain akan ditolak Roblox saat diberi izin akses.

Belum ada riwayat.

Lagu yang kamu upload bersifat privat, jadi hanya bisa dipakai akunmu. Di sini kamu bisa memberi izin supaya lagu yang sudah disetujui bisa dipakai komunitas, akun, atau experience tertentu.

Izin yang sudah diberikan tidak bisa dicabut lewat program ini, dan mungkin tidak bisa dicabut lewat website juga. Periksa ID-nya baik-baik.

Kunci API perlu izin Asset Permissions (Write). Kalau belum, buka kuncinya di Creator Hub lalu tambahkan. Kalau izin kunci kurang, Roblox bisa saja membalas berhasil padahal tidak diterapkan, jadi cek juga hasilnya di Creator Hub.

Pilih dari hasil pencarian untuk menambahkannya ke daftar di bawah.

Masukkan ID manual (termasuk experience)

Izin per lagu

Centang lagu dan target yang mau diberi izin. Kotak di kepala kolom memilih semua lagu untuk target itu, kotak di kepala baris memilih semua target untuk lagu itu, dan kotak paling kiri atas memilih semuanya. Kotak yang terkunci berarti izinnya sudah diberikan. Lagu yang belum disetujui Roblox belum bisa dipilih.

Universe ID bukan Place ID. Cari di Creator Hub, di halaman experience yang bersangkutan.

Susun playlist lalu simpan sebagai file .lua di folder playlist (di samping program ini). Kalau temanmu sudah punya playlist, tempel kodenya di bawah, lalu lanjutkan menambah lagu baru.

Impor dari kode Lua (misalnya dari temanmu)

Tempel seluruh kodenya, mulai dari return {. Program membaca DisplayName, ImageId, dan tiap lagu (Artist, Order, SongId, CustomSpeed). Urutan mengikuti Order. Hasilnya jadi playlist baru yang bisa kamu tambah dan ubah.
